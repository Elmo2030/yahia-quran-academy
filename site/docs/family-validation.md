## 2. Usability session (parental consent; no recording by default)

Recruit five families per intended age band (6–7, 8–9, 10–11) for formative rounds. Use temporary named-child profiles on a test device; never collect real names, recital audio, private family information or browsing histories. Parents may stop at any time. These samples guide iteration, not statistical efficacy claims.

| Task | Neutral instruction | Observe | Success criterion |
| --- | --- | --- | --- |
| First entry | Choose something you want to learn | First action, hesitation, adult assistance | Child identifies an action without coaching |
| Resume | Leave a story/episode before answering; return through My Journey | Correct item and title recognition | Correct content opens, no other child's history |
| Challenge | Read and try the question | Incorrect-answer recovery, reward meaning | Child understands feedback and can continue |
| Parent | Look at this test child's existing parent area | What happened / help needed / next action | Parent explains these in 30 seconds; distinguish completion from understanding |
| Recovery | Reload; then switch to a second test child | Preserved state and separation | No loss or cross-child state |
| Accessibility | Repeat navigation with keyboard; inspect Arabic/English | Focus, labels, direction, touch, text | No task-blocking obstacle |

Run at 375×812, 390×844, 768×1024 and desktop where available. Record device/viewport and locale; do not mark untested dimensions as passed. Use anonymous participant codes, help count, task outcome and short observations only. Retain notes only for the agreed research period; no analytics service is required.

Suggested formative gate: at least four of five participants per band identify the main action without coaching; no critical task blocker; repeat affected tasks after a fix. This is not proof of universal usability.

## 3. Small recall study using existing content

Do not add a review engine, progress state, score, notification, or forced quiz. After the reviewer approves `st-1-05`, use its existing core lesson and reflection in a supervised study. Ask the existing question without showing choices, then permit rereading. Repeat in a later session at a pre-agreed interval, using the same approved material. Explain that this is not an exam.

Record whether the child recalls the idea unaided, with help, or not yet; do not infer mastery. Report invited/participating/followed-up counts and missing follow-ups separately. Parent reports of applying responsibility are self-reports, not independently verified behavior. Hifz recital quality remains exclusively parent-reviewed.

## 4. Decisions after observations

- Improve the existing parent summary only when a repeated comprehension problem is observed. Do not pre-emptively build a dashboard or describe completion as learning mastery.
- Keep Journey restructuring separate until the owner supplies its new direction.
