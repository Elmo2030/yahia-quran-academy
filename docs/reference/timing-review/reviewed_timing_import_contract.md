# عقد استيراد توقيتات المراجعة

> هذا العقد يضيف **مسودة داخلية غير معتمدة** فقط. لا يفعّل تمييز الآيات أو الكلمات في القارئ العام.

## النطاق الحالي

المرحلة التجريبية تقبل سورة الفاتحة فقط، لأنها مربوطة بمسار R2 `surahs/001.m4a` وتجزئة SHA-256 `75bc1954341dadff60b35be00732a6eab85c074beeaeca2e3165f1c2164b743e`. يجب أن تكون قيمة `schemaVersion` هي `timing-review-v1`.

| الحقل | المتطلب |
|---|---|
| `schemaVersion` | `timing-review-v1` فقط |
| `surahNumber` | `1` في المرحلة التجريبية |
| `audio.path` و`audio.sha256` | مطابقان حرفيًا لملف R2 المعتمد |
| `entries` | مقطع واحد على الأقل، بلا تداخل، مع بداية ونهاية بالميلي ثانية |
| `speakerPass` | `teacher` أو `children`، ولا يقبل `unknown` من الاستيراد |
| `canonicalText` | النص الذي راجعه المختص للمقطع |

كل سجل مستورد يبدأ بحالة `needs_review` حتى يراجعه مدير الموقع، حتى لو كان قادمًا من مراجع مؤهل. لذلك لا توجد طريقة للاستيراد المباشر إلى حالة معتمدة أو إلى القارئ العام.
