# Yahia Quran Academy — قارئ الحُصَري المعلّم المتزامن

**تاريخ التوثيق:** 27 أغسطس 2026

**النطاق:** تطبيق Flutter، فرع `manus/timed-solo-reader`

## ملخص الإصدار

يعتمد التطبيق الآن مكتبتين صوتيتين منفصلتين. المكتبة الافتراضية هي **الحُصَري المعلّم المنفرد المتزامن**، وتستخدم فقط ملفات الصوت الموجودة تحت `recitations/husary-muallim-solo/` في R2 مع فهرس وتوقيتات مقترنة بها. أما **مصحف الحُصَري مع الأطفال** فهو مكتبة إضافية مستقلة تقرأ ملفات `surahs/` الموروثة، ولا تحمل توقيتات آيات أو كلمات ولا يجوز أن تعرض تمييزًا زمنيًا.

| المجال | التنفيذ الموثق |
| --- | --- |
| المصحف الافتراضي | `husary_muallim_timed`، الحُصَري المعلّم المنفرد |
| التشغيل | سورة كاملة للمكتبتين؛ تدريب آية بآية للشيخ فقط بعد تحقق فاشل الإغلاق من التوقيت |
| التمييز | آية وكلمة للشيخ عند وجود توقيت كلمة مكتمل، وآية فقط في 13 حالة تغطية كلمة جزئية |
| مكتبة الأطفال | تشغيل سورة كاملة بلا توقيت أو تمييز آية/كلمة |
| الحلقة التعليمية | استمع → كرّر → سجّل → راجع ذاتيًا؛ بلا درجات أو قرارات إتقان آلية |

## ضوابط صحة المحتوى

يقرأ `recitation_manifest.json` كتالوج الشيخ المعتمد ويقبل التوقيت فقط إذا طابق معرّف التلاوة والسورة وبصمة SHA-256 وحجم الملف ومدته. أي فقد أو اختلاف في هذه البيانات يوقف التوقيت بدل التخمين. يظل النص القرآني **Tanzil Uthmani** دون تطبيع أو تعديل.

> لا تُنقل توقيتات الشيخ إلى مكتبة الأطفال، ولا تتحول أي مراجعة ذاتية إلى حكم آلي على التلاوة أو الإتقان.

مصدر المزامنة هو مجموعة الحُصَري المعلّم ذات المعرّف 12 من QUL/Tarteel، ويشير الكتالوج المنشور إلى تقرير التدقيق المطابق للملفات المرفوعة إلى R2. [1] [2]

## التحقق المنجز

| الفحص | النتيجة |
| --- | --- |

| APK/AAB Android | محجوب: لا توجد Android SDK أو `ANDROID_HOME` في البيئة الحالية |

## حدود النشر التالية

يمكن دمج كود Flutter بعد مراجعة طلب السحب. أما نشر Android أو Play Console فلا يمكن تأكيده من هذه البيئة حتى يتوفر Android SDK وإعداد التوقيع، أو خط أنابيب CI موثوق بصلاحية النشر. لا يتضمن هذا الإصدار ملفات MP3 داخل Git أو Flutter assets، ولا أسرار وصول داخل الكود.
